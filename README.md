# Florentine Pixel Recolor

Pixel-art recoloring tool for The Florentines.

Features:

- Florentine NFT fetch by token id
- SGB palette presets
- Custom 4-color palettes
- Random palette generator
- 1x1, 2x2 and 3x3 grid mode
- PNG export
